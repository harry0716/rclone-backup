隱私權政策

本政策適用於 Harry Wang 維護、供本人使用的 rclone-backup OAuth 應用程式及其說明網站。

1. 存取的資料與用途

本工具為執行個人檔案備份，依使用者授權讀取 OneDrive 的檔案內容、檔名、目錄結構及相關中繼資料，並在 Google Drive 建立、讀取或更新備份檔案與資料夾。

Google Drive 使用 drive.file 範圍，存取限於此應用程式建立或使用者明確授權的檔案。OAuth 權杖僅用於連線及維持使用者授權。

2. 處理與儲存位置

rclone 在使用者自己的電腦執行。跨雲端檔案傳輸經過該電腦及其網路，備份內容儲存在使用者的 Google Drive。OAuth 權杖與連線設定儲存於本機 rclone 設定檔；若啟用紀錄，日誌可能含有檔名、路徑、傳輸狀態及錯誤資訊。

此說明網站不接收備份內容、OAuth 權杖或用戶端密鑰，也不提供檔案上傳功能。

3. 資料分享與用途限制

資料僅為使用者要求的備份作業，傳送至 Microsoft OneDrive、Google Drive 及執行 rclone 的電腦。不出售使用者資料，不用於廣告投放、使用者剖析或訓練人工智慧模型。

rclone-backup 對 Google API 所取得資訊的使用及轉移，遵循 Google API Services User Data Policy，包括 Limited Use 要求。

4. 保存、刪除與撤銷授權

備份檔案保留至使用者自行刪除，或依使用者設定的保留規則處理。使用者可在 Google Drive 刪除備份，並視需要清空垃圾桶；雲端供應商可能依其政策保留版本或復原資料。

使用者可透過 Google 帳戶的第三方連線管理撤銷本應用程式授權，並移除本機 rclone 的相關設定與日誌。撤銷授權會停止後續存取，不會自動刪除既有雲端備份。OneDrive 授權可在 Microsoft 帳戶相應的應用程式權限設定中管理。

5. 安全措施

rclone 使用雲端服務提供的 HTTPS API 傳輸資料。使用者應妥善保護執行電腦、rclone 設定檔、OAuth 權杖及用戶端密鑰，避免將其上傳至公開儲存庫。

6. 網站託管

本靜態網站由 GitHub Pages 託管，頁面未加入分析追蹤程式、廣告或表單。GitHub 可能依其服務運作需要處理訪客 IP 位址及連線紀錄，詳見 GitHub 隱私權聲明。
